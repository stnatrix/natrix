# natrix

Personal portfolio and central project hub for [stnatrix.space](https://stnatrix.space).

## Projects
- **[toolstrix](https://github.com/stnatrix/toolstrix)**: Clean personal media downloader powered by yt-dlp, FastAPI, and cgroups v2 (`tools.stnatrix.space`).
- **[ahktrix](https://github.com/stnatrix/ahktrix)**: AutoHotkey v2 QoL utilities (`ahk.stnatrix.space`).

## Stack
- Pure HTML5 / CSS3 / Vanilla JS (no frameworks, zero external CDN dependencies)
- Self-hosted Nunito typography
- Web Audio API synthesizer for tactile click audio
- Nginx reverse proxy with gzip and security headers

## Architecture
See `gemini.md` for virtual host configuration, paths, and deployment scripts.
